<h1>About Us</h1>

openGauss is an open source database that combines high performance, reliability, security, and intelligence. Driven by technological innovation, it significantly boosts cluster performance through advanced techniques like resource pooling architecture and hardware-software collaboration. It also supports financial-grade high availability and large-scale data processing. With integrated AI capabilities, openGauss serves as a data foundation for large models and collaborates with partners to accelerate the evolution of the openGauss ecosystem.

## Open Source History

At HUAWEI CONNECT 2019 on September 19, Huawei announced that its database product would go open source and named it as openGauss.

On June 30, 2020, the source code of the openGauss database went open source officially.
