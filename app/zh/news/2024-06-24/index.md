2024 年 6 月 21日，openGauss Developer Day 2024 在北京隆重举行。在此次峰会中，RISC-V SIG 作为 openGauss 社区的重要合作伙伴，积极参与了 SIG 组版本规划工作会议的关键环节，这标志着 RISC-V SIG 与 openGauss 之间合作的新篇章，同时也展示了开源社区在共建开放生态系统方面的强大动力与多元的行业协同发展景象。


<div style="text-align:center;margin:16px 0;">
  <img src="/category/news/2024-06-24/pic1.png" alt ='' />
</div>


RISC-V SIG Maintainer 吴伟向与会者详细介绍了 RISC-V SIG 的成立背景、其在 openGauss 项目中的重要作用以及针对未来的发展方向。


<div style="text-align:center;margin:16px 0;">
  <img src="/category/news/2024-06-24/pic2.png" alt ='' />
</div>

吴伟强调了 RISC-V SIG 致力于以下几个关键领域：

-  RISC-V SIG 将致力于推动 openGauss 与 RISC-V 的深度整合，将 openGauss 纳入 PLCT 实验室的 RISC-V 支持矩阵观测工程，并计划通过后续努力将 openGauss 纳入 RISC-V 国际基金会的生态展示体系。

-  RISC-V SIG 将加强 openGauss 在更多 RISC-V 设备上的稳定性测试与优化，涵盖 SG2042 Pioneer Box、SG2380 Desktop PC、Laptops 等多种设备，确保 openGauss 在 RISC-V 平台上的稳定运行和卓越性能。

-  此外，RISC-V SIG 还将积极推广 openGauss 在 RISC-V 社区的影响力，计划于 2024 年举办至少 3 场以 openGauss 为主题的 Meetups 活动，吸引更多开发者加入 openGauss 的行列。同时，RISC-V SIG 将 openGauss 加入甲辰计划联合招聘，开放至少 50 名实习名额以注入新的活力。在 RVSPOC 系列比赛中，RISC-V SIG 也将 openGauss 列为推荐优化目标，鼓励参赛者围绕 openGauss 展开创新实践。

<br/>

为了表彰社区成员的贡献，会议期间进行了“一朵小红花奖”的评选，以此彰显社区的共建、共享、共治的理念。每个参加现场会议的 SIG 推举一名“小红花”。RISC-V SIG 全体欢乐地一致推举了刚刚毕业下周一入职但是今天就被拉过来参加会议并且主动写了会议纪要的 PLCT 实验室社区运营经理杨延玲同学（下图头上顶着小红花的那一位）。杨延玲同学虽然刚刚毕业，但是已经作为 PLCT 社区运营实习经理服务 openEuler RISC-V 社区超过两年，帮助 openEuler RISC-V 社区在过去两年中实现了快速、活跃的发展。相信 openGauss RISC-V SIG 在杨延玲经理的帮助下，会快速成为国内活跃有趣的技术社群，并逐步走向海外。

通过 openGauss Developer Day 2024 的交流与合作，RISC-V SIG 与 openGauss 社区共同展望一个技术更丰富、创新空间更广阔的未来。此合作不仅加深了技术交流，也为参与者和开发者们打开了新的合作与发展机会，预示着开源 RISC-V 生态的繁荣发展。
