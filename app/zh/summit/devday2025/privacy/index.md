# openGauss Developer Day 2025隐私政策

<hr/>

openGauss Developer Day 2025由openGauss开源社区主办，并由华为技术有限公司以及其关联公司（以下将“华为技术有限公司”及其关联公司简称「华为」、「我们」和「我们的」）提供各种技术和管理支持。openGauss Developer Day 2025（以下简称「活动」）以中国北京为主活动现场线下活动结合线上直播的形式举行（2025年6月27日），本隐私政策（以下简称「本政策」）将阐述您在注册和参与主活动现场、线上线下活动时华为如何使用和保护您的个人信息。您理解我们收集这些个人信息对于您参加活动是必要的，如果您不提供或不同意我们收集和使用必要的个人信息，您将无法参加openGauss Developer Day 2025。您理解本政策可能并不覆盖活动所有的个人信息处理情景，未覆盖的其他情景将单独提供专门的隐私声明或在后续刷新的政策中阐述。

我们制定本政策的目的在于帮助您了解以下内容：

1. 华为如何收集和使用您的个人信息
2. 华为如何披露您的个人信息
3. 如何访问或修改您的个人信息
4. 华为如何保护您的个人信息
5. 本政策如何更新
6. 如何联系华为

## 1. 华为如何收集和使用您的个人信息

当您阅读并同意本政策后，华为将通过线上和线下两种途径向您收集和处理个人信息，为您提供优质的服务和活动讯息。下文详细列举我们处理您的个人信息的场景、涉及个人信息类型、处理方式以及目的。

1. 为帮助您报名参加活动和享受线上与线下活动体验，我们会使用openGauss开源社区官网收集您的**姓名**、**电子邮箱**、**手机号码**、**单位/公司名称**、**行业**、**职位**，以实现活动注册和报名。为了方便您参会，我们将向您用于注册的**电子邮箱**及**手机号码**发送与活动相关的信息，比如告知您注册结果、参会提醒。
2. 如果您作为特邀嘉宾参与活动，我们将收集您的**照片**、**姓名**、**电子邮箱**、**手机号码**、**公司/单位名称**、**行业**、**职位**、**学校**、**学位**，用于大会宣传物料制作、在大会官网及官方社媒账号上公开宣传。
3. 为了您在本次活动中获得更好的体验感，活动当天入场我们将对您的参会ID进行扫码签到，核对您的报名信息，包含**姓名**、**电子邮箱**、**手机号码**、**单位/公司名称**、**行业**、**职位**。
4. 活动期间我们将安排工作人员在场馆内对活动开展情况进行摄影摄像，或者进行采访，可能处理您的**人像**、**声音信息**，用于大会现场直播、记录与宣传，录制材料包括但不限于电子记录、录像带、录音带和照片。前述录制材料仅用于活动宣传目的，如果您不想入镜或者不愿华为使用与您相关的录制材料，请通过 **<common@public.opengauss.org>** 与我们取得联系。

## 2. 华为如何披露您的个人信息

只有符合下列情况时，华为才会披露您的个人信息：

1. 将您的个人信息披露或转移给其他华为子公司或为活动提供服务的合作方。根据您的请求，华为可能需要通过子公司或合作方为您提供某些服务，例如通过深圳易思智科技有限公司为您提供活动报名及签到服务，及通过重庆狼卜品牌营销策划股份有限公司为您提供摄影摄像服务。因此华为需要将您的部分个人信息共享给该子公司或该合作方，以便向您提供相应服务。华为将严格禁止合作方把您的个人信息用于其他任何目的。
2. 在适用的法律要求或响应法律程序的情况下，华为也可能会向相关的执法机关或者其他政府机关披露您的个人信息。在某些管辖区，如果华为牵涉到重组、合并或破产和清理诉讼，那么您的个人信息还可能会被披露给交易方。
3. 如果您是大会演讲嘉宾，我们将在获得您的授权后，您的姓名、行业、公司、职位、照片、视频将会出现在会议现场，用于大会演讲和现场直播。您的姓名、行业、公司、职位、照片还将会出现在线上如大会官网、openGauss社媒账号、华为官方社媒账号，用于议程展示和活动的宣传。
4. 大会录制视频、大会采访视频将出现在活动宣传中，如大会官网、openGauss社媒账号、华为官方社媒账号，如您不愿华为使用与您相关的录制材料，请及时与我们联系。

## 3. 如何访问或修改您的个人信息

您应确保提交的所有个人信息都准确无误。华为会尽力维护个人信息的准确和完整，并及时更新这些数据。

根据《中华人民共和国个人信息保护法》，您有权随时请求访问和获取副本、接收、反对收集/使用/披露、更改、删除或销毁、拒绝、限制使用和转移您的信息，提出投诉或撤回同意。如果您想行使相关的权利，请 **<common@public.opengauss.org>** 或本政策结尾处的数据保护官的联系方式与我们取得联系。为保障安全，您可能需要提供书面请求。如果我们有合理依据认为这些请求存在欺骗性、无法实行或损害他人隐私权，我们则会拒绝处理请求。

当华为基于您的同意处理您的个人信息时，您还有权随时撤销您的同意。但撤销同意不会影响撤销前我们基于您的同意处理您个人信息的合法性及效力，也不影响我们基于其他适当的合法性基础处理您的个人信息。

## 4. 华为如何保护和留存您的个人信息

华为重视个人信息的安全。我们采用适当的物理、组织和技术保障措施来保护您的个人信息不被未经授权访问、披露、使用、修改、损坏或丢失。例如，我们会使用加密技术确保数据的机密性；我们会使用保护机制防止数据遭到恶意攻击；我们会部署访问控制机制，确保只有授权人员才可访问个人信息；以及我们会举办安全和隐私保护培训课程，加强员工对于保护个人信息重要性的认识。我们会尽力保护您的个人信息，但是请注意任何安全措施都无法做到无懈可击。若发生信息泄露事件，华为会根据所适用的数据保护法律法规处理，并采取所有合理的措施减轻或消除事件的影响。

我们依照法律法规的规定，仅会将收集到的有关您的个人信息存储于中华人民共和国境内。我们不存在跨境存储您的个人信息或向境外提供个人信息的场景。如果确有必要进行数据的跨境传输，我们会单独向您明确告知（包括数据出境的目的、接收方、使用方式与范围、使用内容、安全保障措施、安全风险等），并征得您的授权同意，我们会确保数据接收方有充足的数据保护能力来保护您的个人信息。

我们将会在达成本政策所述目的所需的期限内保留您的个人信息，一年后进行删除处理，除非按照法律要求或许可需要延长保留期或受到法律的允许。

当您主动申请删除您的个人信息时，我们会在1个月内响应您的要求并删除您相关个人数据。

## 5. 本政策如何更新

华为保留不时更新或修改本政策的权利。如果我们的隐私政策变更，我们会将最新版隐私政策发布在这里。如果我们对隐私政策做出了重大变更，我们还可能会通过不同渠道向您发送变更通知，例如，在我们的网站上发布通知或者向您发布单独的通知。欢迎您随时访问本政策了解详细内容。

## 6. 如何联系华为

如果您有任何疑问、意见或建议，请通过发送邮件至 **<common@public.opengauss.org>** 与我们联系。
