# 国际化规范

## 双语同步通用规则

zh / en 是本仓的双语镜像（涉及 ru 时一并同步），以下操作必须同时修改两种语言：

- 翻译文件（`~@/i18n/` 下 zh / en 对应 JSON）
- 页面 frontmatter（`app/zh/` 与 `app/en/` 对应 `.md`）
- SEO TDK 字典（`tdks/zh.ts` 与 `tdks/en.ts` 对应路由键）
- 导航 / banner / 数据配置中 zh / en 双数组

```typescript
// ✅ 双语同步：zh 和 en 各新增一条
homeBanner.zh.push({ title: '新功能', link: '/zh/new-feature/', ... });
homeBanner.en.push({ title: 'New Feature', link: '/en/new-feature/', ... });

// ❌ 只改了一种语言
homeBanner.zh.push({ title: '新功能', link: '/zh/new-feature/', ... });
// en 未同步 → 遗漏
```

## 无对应语言版页面时的边界规则

当新增条目（banner / link / 导航等）的 **link 目标页面仅在一种语言存在**、没有对应语言版页面时：

- **对应语言应省略该条目**，而非强制为该语言创建一条指向异语言页面的条目
- 禁止创建指向异语言页面的条目（如 en 条目 link 指向 `/zh/xxx/`）
- 待对应语言版页面上线后，再同步补充该语言条目

> **为什么 / 踩过的坑**：agent 机械执行"双语同步"红线，为仅有 zh 版页面的 ogmemory 在 en 数组强行新增一条
> link 指向 `/zh/ogmemory/` 的 banner 条目，导致 en 用户点击后进入中文页面，维护者明确拒绝此跨语言链接。

### 示例：首页 banner 配置

```typescript
// ogmemory 页面仅有 /zh/ogmemory/ 版本，无 /en/ogmemory/ 页面

// ✅ 只在 zh 数组新增，en 数组省略
homeBanner.zh.unshift({
  title: 'oGMemory 专区',
  subtitle: '面向AI Agent的长期记忆系统...',
  link: '/zh/ogmemory/',
  btn: '了解更多',
  ...
});
// en 数组不添加此条目 —— 等 en 版 ogmemory 页面上线后再补充

// ❌ 为 en 强行新增指向 /zh/ 的跨语言链接
homeBanner.en.unshift({
  title: 'oGMemory',
  subtitle: 'A long-term memory system for AI Agents...',
  link: '/zh/ogmemory/',  // ← en 用户被导向中文页面
  btn: 'Learn More',
  ...
});
```

## 禁止事项

- 禁止只改一种语言的文案 / 配置而遗漏另一种（通用场景）
- 禁止创建指向异语言页面的条目（如 en 条目 link 指向 `/zh/xxx/`）
- 禁止为仅单一语言存在的目标页面在另一语言数组中强行"同步"——此时应省略该条目
